# 发票打印助手 (fapiao)

A4 纵向批量打印电子发票（PDF / 图片）的桌面小工具，基于 PyQt5。

## 功能

- 选择目录自动扫描发票文件（PDF、PNG、JPG、JPEG、BMP、GIF、TIF、TIFF、WEBP），支持子目录
- 表格管理：勾选要打印的文件、每个文件单独设置旋转角度（左转 90°，可累计，转 4 次还原）
- 打印机下拉选择（自动列出系统所有打印机）
- 原生打印预览（可缩放逐页查看）
- 打印进度条（读取 / 打印两阶段，可取消）
- 排版格式：A4 纵向，发票置顶、等比缩放适配宽度，符合报销打印习惯
- 每页可打 1 张或 2 张（上下排列省纸），页边距可调

## 运行环境

- Python 3.8+
- 依赖：`PyQt5`、`pypdfium2`

```bash
pip install PyQt5 pypdfium2
python invoice_printer.py [发票目录]
```

也可以直接双击 `发票打印助手.bat`（需先按上面的路径修改 bat 中的 Python 与脚本路径）。

## 自测

```bash
python test_app.py
```

offscreen 模式下验证：旋转方向、表格勾选收集、进度打印。

## 使用说明

1. 选择发票目录，点击「扫描文件」
2. 在表格中勾选要打印的发票；方向不对的行点「旋转」列按钮左转 90°
3. 选择打印机、每页张数、页边距
4. 「打印预览」确认效果，或直接「打印」
